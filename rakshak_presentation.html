The Problem 02 / 07

Why SOTA Agents (SWE-Agent, Devin) Fail in Real Dev

Existing autonomous agents are too heavy, too expensive, and prone to silent regressions.

📦 Heavy Docker Overhead

SWE-agent and OpenHands require 5-15GB containers per task. Spin-up takes 3 to 5 minutes, eats up multi-gigabyte RAM, and frequently fails due to container permission errors.

💸 Astronomical Token Bloat

Agents dump raw file trees and full files into context (15k–30k+ tokens per turn). A single bug fix costs upwards of $1.00 - $3.00 in LLM API fees and slows inference.

⚠️ Hallucinated "Fixes" & Regressions

Models claim they fixed the bug, but silently break 5 other existing tests. Most harnesses don't verify candidate vs baseline test parity.

🔒 Single-Language Lock-in

Most benchmarks are rigid Python-only scripts. Real enterprise codebases are polyglot stacks (Python, TypeScript, Go, Rust).

System Architecture 03 / 07

Rakshak's Deterministic Workflow

End-to-end bug localization, iterative synthesis, and mathematical verification.

1. Issue Intake & AST Blast-Radius Localization: Parses GitHub issue / benchmark, scans repository AST call-graphs, and extracts only the relevant classes and functions (~1,500 tokens).
2. Native Isolated Sandbox Execution: Runs on-host native sandbox with strict environment boundaries (`HOME`, `PYTHONPATH`), executing test suite without slow Docker virtualization.
3. Candidate Patch Synthesis: Targeted LLM synthesis produces surgical diffs (not full file rewrites).
4. Dual-Loop Verification Parity Check: Candidate patch is evaluated against baseline suite: Passes(Candidate) >= Passes(Baseline) AND FailingTestNowPasses()
5. Automated Commit & Pull Request: On 100% verification, Rakshak creates a git commit, push branch, and opens/closes the GitHub issue.
💬 Speaker Note: "Notice our dual-loop verification in Step 4. We never accept an LLM's word. A patch is only merged when the harness proves tests pass and zero baseline tests were broken."

Core Innovations 05 / 07

The 4 Technological Breakthroughs

What makes Rakshak uniquely viable for enterprise deployment.

🛡️ Dual-Loop Parity

Guarantees zero regressions. Compares test deltas so fixes don't introduce silent side effects.

📉 AST Slicing

Feeds only the exact call-graph blast radius into the LLM, reducing token cost by over 80%.

⚡ Zero-Docker Core

Runs directly on lightweight runners without root privileges or multi-gigabyte container pulls.

🌐 Polyglot & TUI

Supports Python, JS/TS, Go, and Rust. Features a live interactive Rich Terminal TUI for developers.
